# Introdução
Esta é a primeira versão do meu portfólio pessoal, desenvolvida logo após meus primeiros passos no desenvolvimento web. Ela serviu como meu cartão de visitas inicial e foi o projeto onde consolidei os fundamentos de deploy e hospedagem na nuvem.

# Sobre
A Versão 1 foi concebida como uma landing page estática, focada em apresentar quem eu sou e quais projetos eu já havia desenvolvido. O foco principal foi a simplicidade e a rapidez de acesso, utilizando uma estrutura direta para que recrutadores pudessem encontrar minhas informações de contato e meu GitHub com facilidade.

# Objetivo do projeto
O foco deste projeto foi:
- Estabelecer minha presença online oficial.
- Aprender o fluxo de deploy contínuo utilizando a Vercel.
- Criar uma interface responsiva que funcionasse bem em dispositivos móveis e desktops.

# Meu papel no projeto
Sendo meu primeiro portfólio, fui responsável por:
- Design da interface (UI).
- Desenvolvimento front-end.
- Organização do conteúdo e curadoria dos primeiros projetos exibidos.

# Entendimento do problema
Na época, eu precisava de um lugar centralizado para mostrar meus trabalhos além do GitHub. O desafio era criar algo funcional e visualmente agradável sem utilizar uma stack complexa de banco de dados, focando apenas no que era essencial para um desenvolvedor junior e aspirante a designer.

# Solução proposta
A solução foi uma página única (Single Page Application) com seções bem definidas: Hero, Sobre Mim, Projetos e Contato. Optei por um design de blocos limpos que priorizava a leitura. A manutenção era feita diretamente no código, o que me permitiu praticar a organização de componentes e a estruturação de arquivos estáticos.

# Aprendizados
Este projeto foi fundamental para:
- **Domínio de CSS**: Reforcei conceitos de Flexbox e Grid para criar o layout responsivo.
- **Ecossistema Vercel**: Aprendi a configurar domínios e gerenciar deploys automáticos.
- **Síntese de Conteúdo**: Aprendi a selecionar o que é realmente importante comunicar em uma primeira interação com um usuário.

# Status do projeto
Este projeto está oficialmente "concluído" e serve como um registro histórico da minha evolução. Ele foi a base que me permitiu identificar as melhorias necessárias para a criação da Versão 2, que hoje utiliza uma arquitetura muito mais robusta com Next.js e Supabase.
