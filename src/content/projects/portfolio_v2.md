# Introdução
Este projeto documenta a evolução da minha identidade digital. A transição da Versão 1 para a Versão 2 do meu portfólio não foi apenas uma mudança estética, mas um salto tecnológico para criar uma plataforma escalável, dinâmica e de alta performance.

# Sobre
O projeto consiste no desenvolvimento da minha landing page pessoal. A Versão 1 era um site estático focado na apresentação básica. Já a Versão 2 foi concebida como um web app completo, integrando banco de dados para gestão de conteúdo e um design refinado que reflete meu amadurecimento como Product Designer e Web Developer.

# Objetivo do projeto
O objetivo central da reformulação foi:
- **Dinamicidade**: Substituir arquivos estáticos por um banco de dados (Supabase) gerenciado via Prisma.
- **Storytelling**: Criar modais detalhadas que narram o processo criativo de cada projeto, e não apenas exibem links.
- **Performance**: Otimizar o carregamento e a responsividade utilizando Next.js e Tailwind CSS.

# Meu papel no projeto
Como autor único, fui responsável por todo o ciclo de vida do produto:
- **UX Research**: Analisei meu portfólio anterior para identificar pontos de fricção na navegação.
- **UI Design**: Projetei a nova interface no Figma, focando em uma estética moderna, limpa e com melhor hierarquia visual.
- **Desenvolvimento Full Stack**: Implementei o front-end, a modelagem do banco de dados e a integração com APIs.

# Entendimento do problema
Na Versão 1, a atualização de projetos era um processo manual e demorado. Além disso, a apresentação dos cases era superficial. Eu precisava de uma ferramenta que permitisse gerenciar meu trabalho com agilidade e que mostrasse para recrutadores e clientes a profundidade real de cada entrega.

# Solução proposta
A solução foi reconstruir o portfólio do zero utilizando uma stack moderna. A grande inovação da V2 é o sistema de gestão de projetos: agora, cada "case" é uma entrada no banco de dados com suporte a Markdown, permitindo formatação rica e detalhada sem a necessidade de novos deploys para cada alteração de texto.

# Fluxos e telas desenvolvidas
A nova versão conta com:
- **Landing Page Hero**: Apresentação clara e direta da minha proposta de valor.
- **Grid Dinâmico de Projetos**: Filtros por categoria (Web/Design) que buscam dados em tempo real.
- **Sistema de Modais**: Visualização expandida de projetos com renderização de Markdown para estudos de caso.
- **Dashboard Administrativo**: Uso do Prisma Studio para gerenciamento rápido de conteúdo.

# Evolução (V1 vs V2)
- **V1**: Site estático, design focado em blocos simples, sem persistência de dados.
- **V2**: Web App dinâmico, design system próprio, integração com Supabase/Prisma e SEO otimizado.

# Aprendizados
Este projeto foi o meu laboratório para aprender a integrar o Prisma no ecossistema Next.js. Reforcei conhecimentos em modelagem de dados (Enums, Relacionamentos) e entendi como o design pode guiar a arquitetura técnica de uma aplicação.

# Status do projeto
Versão 2 em fase final de implementação e substituição da versão anterior.
